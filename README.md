# TeraFab: o maior prédio da história é uma fábrica de chips

Vídeo curto (PT) do INEMA com o avatar do Nei Maldaner, em 16:9 e 9:16.

O Elon Musk vai erguer no Texas a TeraFab: mais de 100 milhões de pés quadrados sob um telhado só,
cinco vezes o maior prédio de hoje. O motivo: segundo o Musk, todas as fábricas de chip do mundo
entregam só uns 2% do que as empresas dele vão precisar. A meta é chegar a até 200 bilhões de chips por ano.
